Add Kitchen Hub to your Home Screen
  1. Open your browser's Share or menu.
  2. Choose Add to Home Screen.
  3. On iPhone or iPad, if you see Open as Web App, turn it off.
  4. Tap Add.
Add Kitchen Hub to your desktop
Chrome or Edge
  1. Open the browser menu (⋮).
  2. Choose Create shortcut or Install this site as an app. It may be under Save and share or Apps.
  3. Keep the name Kitchen Hub, then choose Create or Install.
  4. If offered, pin it to the desktop, taskbar or Start menu.
Safari on Mac
  1. Open the File menu.
  2. Choose Add to Dock.
  3. Keep the name Kitchen Hub and confirm.
Open Kitchen Hub

The shortcut opens Kitchen Hub in your default browser and can use that browser's existing Google sign-in.

The shortcut opens Kitchen Hub through the browser you create it from and can use that browser's existing Google sign-in.
