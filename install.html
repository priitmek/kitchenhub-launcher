Add Kitchen Hub to your Home Screen
  1. Open your browser's Share or menu.
  2. Choose Add to Home Screen.
  3. On iPhone or iPad, if you see Open as Web App, turn it off.
  4. Tap Add.
Add Kitchen Hub to your desktop
Firefox on a shared Windows PC Recommended

Use a Firefox Private Window on shared computers. This keeps Kitchen Hub and the Function Manager's Google sign-in separate from the normal Firefox session and clears that private session after every private window has been closed.

  1. On the Windows desktop, right-click and choose New → Shortcut.
  2. Paste the target below.
  3. Name the shortcut Kitchen Hub.
  4. Open Kitchen Hub using this shortcut and sign in with the approved Google account.
  5. When finished, close every Firefox Private Window so the private Google and Kitchen Hub session is cleared.

Personal or single-user PC

If nobody else uses the computer, a dedicated Firefox profile can remember the correct Google account between sessions. Do not use this option on a shared staff computer.

  1. In Firefox, enter about:profiles in the address bar.
  2. Choose Create a New Profile and name it exactly Kitchen Hub.

Chrome or Edge on Windows
  1. Open the browser menu (⋮).
  2. Choose Create shortcut. It may be under Save and share.
  3. Keep the name Kitchen Hub and choose Create.
  4. If Open as window is offered, leave it off so Kitchen Hub uses your normal browser session and Google sign-in.
Mac
  1. Leave this Kitchen Hub page open.
  2. Drag the website icon or address from the browser's address bar onto your Desktop.
  3. Rename the shortcut Kitchen Hub if needed.
  4. Open it normally whenever you need Kitchen Hub.
Open Kitchen Hub

The shortcut opens Kitchen Hub in your default browser and can use that browser's existing Google sign-in.

On shared Firefox computers, use the Private Window shortcut and close every private window when finished. The shortcut opens the production Kitchen Hub address directly.
